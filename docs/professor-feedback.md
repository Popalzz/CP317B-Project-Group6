# Professor Feedback

## Order-Ahead

The professor said that one of the functional requirements for the Food Delivery System could be an order-ahead feature.

### Idea

A customer should be able to schedule an order for a future time or create a recurring order.

Example:

- A customer pays or sets up an order in advance.
- The customer chooses a recurring schedule, such as every Friday.
- The same food order, such as a pizza, is automatically ordered and delivered according to that schedule.
- The recurring order continues until the customer cancels it or they run out of funds in said account

### Possible Functional Requirement

**FR:** The system shall allow customers to schedule food orders for a future date and create recurring food orders for selected days and times.

### Possible User Story

**As a customer, I want to schedule recurring food orders so that I can receive meals I regularly order without having to manually place the same order each time.**

### Notes

We should decide as a group how the payment portion will work.

Options we could do:

1. Charge the customer separately each time the recurring order is processed.
2. Allow the customer to add prepaid credit that is used for recurring orders.

Not a main requirement but something we can look into for sure
